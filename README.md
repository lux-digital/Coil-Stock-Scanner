# Coil Stock Scanner

Open `index.html` from a web server (or the repository's hosted page), take/select a photo, and scan. The app finds the blue Unionsteel label, corrects its perspective and orientation, reads the printed fields, and shows the straightened label with editable results. Photos and results stay in the browser. The OCR library needs an internet connection on first load.

On a phone, tap **START LIVE SCANNER** and allow the site's camera request. Keep the full blue label in view; small hand movements are fine. The scanner checks sharpness and glare for several frames before the green overlay and checkmark, then checks the actual saved frame again. A two-tone chime plays once it has saved the photo, so you can lower the phone without looking at the screen. Tap **TEST CAPTURE SOUND** before raising the phone, and check the phone's volume and silent setting if you do not hear it. There is no time-based forced capture; tilt the phone slightly to avoid a flashlight reflection, or use **CAPTURE NOW** and the photo picker as fallbacks. On iPhone, open the page in Safari and use Share → Add to Home Screen; `coil-icon.png` is the home-screen icon.

The live outline tries a lower contrast blue boundary when shadows or low exposure prevent the normal detector from finding the full label. Automatic capture still waits for a sharp, steady frame. If the outline misses the label, tap **DOWNLOAD TEST REPORT** while the camera is still showing it, then attach the ZIP to the chat. The report contains a camera frame, the drawn boundary, the blue-pixel mask used for that boundary, camera dimensions, and recent detection decisions. **CAPTURE NOW** scans without waiting for the outline. After a scan, the result's report button additionally includes the original photo, straightened and enhanced images, raw OCR text, detected values, and validation details. Nothing is sent to a server by this button; it only saves a ZIP on the phone.

The scanner extracts the printed colour name **or** printed colour code, depending on the label. If the name is cut off on the label, the printed code is used and flagged for review. It does not look up a colour name from a code. It reads the original and enhanced crops separately where that improves OCR, and retries the large part number, barcode caption, colour code and metric strip when needed. A single OCR digit may be corrected when an independently printed unit pair corroborates it; that field stays flagged for review. Missing readings stay blank instead of being calculated from another unit. Always check the values against the straightened photo before using them. The sample photos in `test-photos` include glare, tears, perspective angles, and partial text that OCR cannot reliably recover.

`scanner-core.js` handles label detection and perspective correction; `scanner-parser.js` extracts printed values; `scanner.js` handles browser OCR, display, and unit checks. Run `node test/scanner-parser.test.js` and `node test/live-capture.test.js` for regression checks. The test photos remain unchanged.
